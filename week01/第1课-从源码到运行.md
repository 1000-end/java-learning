## 一、三个名词，一次说清

| 名词 | 是什么 | 打个比方 |
|---|---|---|
| **JVM**（Java 虚拟机） | 真正执行程序的「机器」，一个软件 | 会读字节码的翻译官 |
| **JRE**（运行环境） | JVM + 核心类库（String、System 这些） | 翻译官 + 字典 |
| **JDK**（开发工具包） | JRE + 编译器 `javac` + 一堆工具 | 翻译官 + 字典 + 教你怎么写的教材 |

关系：**JDK ⊃ JRE ⊃ JVM**。
所以你装的是 JDK：既能写代码，也能跑代码。只装 JRE 的人只能跑，不能写。

## 二、一条链：源码怎么变成能跑的东西

```
Hello.java  ──(javac 编译)──►  Hello.class  ──(JVM 执行)──►  屏幕上出现文字
  人写的            字节码（给 JVM 看的）         JVM 把字节码翻译成机器指令
```

关键点：

- **`.java` 是给人看的，`.class` 是给 JVM 看的**。`.class` 里不是 0101 机器码，是「字节码」——一种介于两者之间的中间语言。
- **跨平台靠的是 JVM**：同一份 `.class`，在 Windows 上由 Windows 版 JVM 执行，在 Linux 上由 Linux 版 JVM 执行。所以叫「一次编译，到处运行」。跨的是 JVM，不是你的代码。
- 所以装 JDK 要选对系统：你选的是 **Windows x64**，装到别的系统上就不认。

## 三、动手（在 IDEA 里做）

### 3.1 建工程
1. IDEA 欢迎页 → **新建项目 / New Project**
2. 左侧 **Java**，名称 `hello-demo`
3. 位置选 `D:\ai\deepseek\dsh-workplace\java\week01`
4. SDK 选 **21**（没有就 Add JDK → `D:\ai\deepseek\dev\jdk-21.0.13`）
5. 构建系统选 **IntelliJ**，创建

### 3.2 写第一个类
1. 左侧 `src` 右键 → **新建 → Java 类** → 输入 `Main`
2. 输入 `psvm` 按 Tab，再输入 `sout` 按 Tab，补全成：

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
        System.out.println("我叫韩睿昊，这是我第一个 Java 程序");
    }
}
```

逐字解释这四行（**这是本课最重要的部分**，别跳过）：

| 片段 | 什么意思 |
|---|---|
| `public class Main` | 定义一个「类」，名字必须和文件名 `Main.java` 一致（大小写也要一致） |
| `public static void main(String[] args)` | 程序的**入口**。JVM 只认这一个签名，少一个 `static` 就跑不起来 |
| `System.out.println(...)` | 向控制台输出一行，`println` 结尾带换行，`print` 不带 |
| `;` | 每条语句必须以分号结尾，中文分号 `；` 不行 |

3. 点 `main` 左边的绿色三角 → **运行**
4. 下方 Run 窗口出现两行输出 → 成功

### 3.3 看穿 IDEA 背后的动作（重点）
按 `Alt + F12` 打开 IDEA 内置的终端（Terminal），在**项目根目录**执行：

```powershell
cd src
javac -d ..\out Main.java
dir ..\out
java -cp ..\out Main
```

你会看到：

1. `javac` 编译后，`out` 目录里多了一个 **`Main.class`**
2. `java -cp ..\out Main` 把它跑起来

> `-d ..\out` = 把编译结果放到 out 目录；`-cp ..\out` = 告诉 JVM 去哪里找类。
> 这就是 IDEA 那个绿三角偷偷替你做的事。

### 3.4 故意把它弄坏（学会读报错）
把下面三种错误各试一次，看清报错说的是什么：

| 改动 | 你会看到 | 说明 |
|---|---|---|
| 删掉行尾的 `;` | `';' expected` | 编译期错误，最基础的一类 |
| 把 `class Main` 改成 `class main` | `class main is public, should be declared in a file named main.java` | 类名必须和文件名一致 |
| 把 `public static void main` 的 `static` 删掉 | `Main method is not static...` | JVM 找不到入口 |

**记住这个感觉**：Java 的编译期很严格，很多错误根本跑不到运行期就被抓住了——这是 Java 相对 C 更省心的地方。
